# Firebase Timeslot Configuration - Quick Reference\n\n## Collection: `timeslot_availability`\n\n### Document ID Format\n```\nYYYY-MM-DD (e.g., \"2025-12-15\")\n```\n\n### Document Structure\n```javascript\n{\n  date: \"2025-12-15\",              // Same as document ID\n  slots: {\n    \"8:20 AM\": false,              // false = blocked\n    \"9:20 AM\": true,               // true = available (optional)\n    \"10:20 AM\": false\n  },\n  updatedAt: timestamp,             // ISO string\n  updatedBy: \"admin\"                // User email\n}\n```\n\n## Code Examples\n\n### Read Timeslot Availability\n```javascript\nconst dateStr = \"2025-12-15\";\nconst doc = await db.collection('timeslot_availability').doc(dateStr).get();\n\nif (doc.exists) {\n  const slots = doc.data().slots;\n  const isBlocked = slots[\"8:20 AM\"] === false;\n  const isAvailable = slots[\"9:20 AM\"] !== false;\n}\n```\n\n### Write/Update Slots\n```javascript\nconst dateStr = \"2025-12-15\";\nconst slotTime = \"8:20 AM\";\nconst isEnabled = true; // or false\n\nawait db.collection('timeslot_availability').doc(dateStr).set({\n  date: dateStr,\n  [`slots.${slotTime}`]: isEnabled,  // \"slots.8:20 AM\": false\n  updatedAt: new Date().toISOString(),\n  updatedBy: 'admin'\n}, { merge: true });\n```\n\n### Toggle Slot (Block/Unblock)\n```javascript\nconst dateStr = \"2025-12-15\";\nconst slotTime = \"8:20 AM\";\n\nconst doc = await db.collection('timeslot_availability').doc(dateStr).get();\nconst isCurrentlyEnabled = doc.data()?.slots?.[slotTime] !== false;\nconst newState = !isCurrentlyEnabled;  // Toggle\n\nawait db.collection('timeslot_availability').doc(dateStr).set({\n  date: dateStr,\n  [`slots.${slotTime}`]: newState,\n  updatedAt: new Date().toISOString(),\n  updatedBy: 'admin'\n}, { merge: true });\n```\n\n## Files to Check\n\n| File | Function | Line |\n|------|----------|------|\n| `appointment-scheduler.js` | `loadUnavailableSlots()` | ~606 |\n| `appointment-scheduler.js` | `saveUnavailableSlots()` | ~632 |\n| `appointments.js` | `getTimeslotAvailability()` | ~606 |\n| `appointments.js` | `updateTimeslotAvailability()` | ~625 |\n| `firestore.rules` | Firestore rules | ~193 |\n\n## Firestore Rules\n\n```\nmatch /timeslot_availability/{dateDoc} {\n  allow read: if request.auth != null;\n  allow write: if request.auth != null && isAdmin(request.auth.uid);\n}\n```\n\n**Read**: Any authenticated user\n**Write**: Admin users only\n\n## Common Mistakes ❌\n\n```javascript\n// ❌ WRONG: Using slot ID instead of time\nslots: { \"slot1\": false }  // Don't use this\n\n// ✅ CORRECT: Using slot start time\nslots: { \"8:20 AM\": false }  // Use this\n\n// ❌ WRONG: Not converting boolean correctly\nslots: { \"8:20 AM\": \"blocked\" }  // String, not boolean\n\n// ✅ CORRECT: Use boolean values\nslots: { \"8:20 AM\": false }  // Boolean\n\n// ❌ WRONG: Storing entire slots array\nslots: [{date, time}]  // Array structure\n\n// ✅ CORRECT: Use key-value object\nslots: {\"8:20 AM\": false}  // Object structure\n```\n\n## Testing in Firebase Console\n\n1.
